# Personal GitHub account usage

Use this guidance for personal repositories. Work-account guidance lives in `work.md`.


## Account

Use the `dusktreader` GitHub account for repositories owned by `dusktreader`.


## Rules

- Before a `gh` operation, confirm the active account with `gh auth status`.
- Never use any `gh` command that pushes commits or refs (e.g. `gh pr create`
  after an unpushed branch) without confirmation from the user
- Never submit a PR review, comment, reply, or inline comment unless the user explicitly approves the exact text and
  target. A request to review a PR authorizes analysis only, not publication. Present the draft and wait for approval.
